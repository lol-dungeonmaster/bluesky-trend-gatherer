Authentication (Optional)

By default, this extension synchronizes with your active Bluesky tab to bypass rate limits. If you want the extension to run completely autonomously in the background (even when the Bluesky tab is closed), you can provide an official App Password.

Database Management

Export your archived timeline shifts into a compressed Apache Parquet file for deep analysis in Jupyter Notebooks or Pandas.

Restore a previously exported timeline backup. Identical snapshot timestamps are automatically deduplicated.

Permanently wipe all collected timeline data from the local OPFS database. This action cannot be undone unless you have a backup.
